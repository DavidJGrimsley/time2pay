# Partnership Keys

This folder stores public-only key artifacts used for partner onboarding.

Allowed:
- Armored public keys (`*.asc`)
- Fingerprint text files (`*-fingerprint.txt`)

Not allowed:
- Private keys
- Revocation certificates
- Any secret material

Recommended file names for Mercury:
- `mercury-time2pay-public.asc`
- `mercury-time2pay-public-fingerprint.txt`
